Mission

The Structural Xploration Lab (SXL) at EPFL is developing REON, an AI system that predicts the reuse value of building components before demolition, turning research validated on 23,200 real reuse-market transactions into a working product.

We are looking for a software developer to help build the core of this product alongside the founder: taking a validated research prototype and turning it into a clean, working, deployable tool.

  • Main duties and responsibilities

Responsabilités principales

  • Main duties and responsibilities
  • Extract and harden a scoring engine from an existing Python/Streamlit prototype into robust, standalone code
  • Rebuild the data layer from Neo4j to a Python-native graph structure
  • Implement data-ingestion and similarity-matching logic that completes missing component information (GNN)
  • Build a lightweight web interface: data upload in, ranked results out
  • Work independently from rough goals to working software, using modern tooling (including AI coding assistants) to move fast
  • Keep the codebase clean and documented so it can be extended by others. Profile
  • We are looking for a strong early-career Python developer who is interested in bringing a research prototype into a working product.
  • The role combines graph data, ML, and practical web development.
  • Some technologies may be learned during the project, but solid Python skills and hands-on experience with graphs and GNNs are essential.

  • Familiar with Git; experience with LLM workflows, Docker, or cloud deployment is an advantage
